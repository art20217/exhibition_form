# 使用指南

給展場接待與業務人員。不需要任何技術背景。

平板或手機瀏覽器開啟：https://art20217.github.io/exhibition_form/

> 建議展前把它**加入主畫面**，之後就像一般 App 一樣開啟，而且完全離線可用。

## 展前準備

1. 用平板瀏覽器開啟表單網址（或直接開啟 `index.html` 檔案），畫面停在活動首頁。
2. 點擊右上角齒輪圖示，輸入 PIN `0000` 解鎖活動管理。
3. 點「＋ 新增活動」建立這次的展覽：填活動名稱（如 `2026 美國展`）、活動起訖日期、這次參展的接待人員（英文＋中文）。**表單欄位來源**選「內建預設欄位」，或選「複製自」上一場展覽以沿用已調整好的選項。
4. 仍在活動管理（已解鎖）的畫面上，點「系統設定」：修改裝置名稱（如 `Tablet-A`）、修改 PIN 碼、修改 GDPR 聲明文字（替換為公司名稱），需要雲端同步時也在這裡填同步伺服器。**此頁為全域設定，每台平板只需設定一次**，不隸屬於任何一場活動。
5. 點進剛建立的活動，再點右上角齒輪輸入 PIN 進入後台。
6. 進入 **客戶資料欄位** / **客戶需求欄位** / **公司背景欄位**：依這次展覽的需求調整欄位和選項，按住把手拖曳調整順序。例如在「感興趣產品」中新增產品線名稱。這些設定只影響這一場活動。

   > 多台平板共用同一場活動時，**欄位只有建立活動的那台改得動**，其他平板看到的是唯讀的欄位清單，並標明由哪台裝置管理。真的需要在別台改，就在活動管理的卡片上點「接管欄位設定」（一層確認），接管後對方會變成唯讀。
7. 點擊「← 返回表單」回到活動頁。
8. 如有多台平板，每台重複上述步驟，確保裝置名稱不同。

## 展覽現場操作

1. 在活動首頁點進這次的展覽。
2. 業務先在活動頁點選**自己的名字**（兩人以上一起接待就複選）與**填單日期**，兩者都選好後兩個表單入口才會亮起。
3. 客戶到訪時，先選「客戶公司背景」，再選從哪張表開始（可由客戶自填或業務協助輸入）：
   - **新客戶** — 要填公司背景，共三步驟。
   - **舊客戶** — **跳過公司背景**，只有兩步。公司背景已經有了，不必重填。
   - 下方兩個入口「**從客戶資料開始**」「**從客戶需求開始**」只決定順序，兩個都到得了全部欄位。
   > 這個選擇**每填完一筆就會重置**，因為下一位訪客是新是舊每次都可能不同。填單人員與日期則會保留。
4. 第一步填完按「Next 下一步」，依序完成後續步驟，最後一步按「Finish 完成」。畫面右上角的步驟標示（新客戶 `1 / 3`、`2 / 3`…；舊客戶 `1 / 2`、`2 / 2`）會告訴你還剩幾步。（訪客國籍／語言在客戶資料頁填寫，國籍是可搜尋的國家選單——輸入中文或英文都能篩選，**清單裡沒有的國家直接打字即可**；感興趣產品／成交機率／備註在客戶需求頁填寫；名片拍照在客戶資料頁尾。）
   > **拍名片時讓名片盡量填滿畫面。** 照片會壓縮後保存，卡片佔畫面越小、字就越糊。這張圖是日後唯一的名片存檔（系統不做文字辨識），拍得太遠事後補不回來。
5. 交接畫面出現後請客戶將平板交還，業務點右下角「完成，返回」回到活動頁。填單人員與日期已自動寫入這筆紀錄。
6. 回到活動頁後上方會顯示目前的填單人員與日期，同一位業務可直接接待下一位客戶；**換人時記得點「重新選擇」改成自己的名字**。

## 查詢與修改已填的紀錄

活動頁下方的「**客戶資料紀錄**」可以查看這場活動已經填過的所有紀錄，需要輸入 PIN。

- 用上方搜尋框輸入**姓名、公司或接待人員**即時篩選。
- 點任一筆即可編輯，改完存檔會回到列表。
- 這個頁面**不能刪除、也不能匯出**——那兩件事在「表單管理」裡。

適合客戶留錯電話、公司名打錯、或是快速填單後想補上公司背景的情況。

## 展後匯出

1. 進入該活動 → 後台 → 資料紀錄 頁籤。
2. 點擊「匯出資料」，等待 ZIP 檔案下載完成（只會匯出這一場活動的資料）。
3. 解壓後用 Excel 開啟 `records.xlsx`，照片在 `cards/` 資料夾中。
4. 匯出確認無誤後，回到活動首頁把這場活動設為「結束活動」——資料仍保留、隨時可以再匯出，但表單入口會停用，避免之後誤填到舊活動。若確定不再需要平板上的資料，可執行「清除本活動全部紀錄」或直接刪除該活動。

## 遇到問題時

**平板一直顯示舊版本，重新整理也沒用**
在網址後面加上 `?sw=off` 開啟一次：
`https://art20217.github.io/exhibition_form/?sw=off`
這會清掉離線快取並取得最新版本，**不會刪除任何已填寫的紀錄**。
之後活動首頁底部會顯示「離線快取已停用」；要恢復離線功能，改用 `?sw=on` 開啟一次。

**看到「有新版本」橫幅**
只會出現在活動首頁，按「立即更新」約幾秒完成。填表途中不會跳出來，也不會自己重整。

**忘記 PIN 碼**
預設 `0000`，可在「活動管理 → 系統設定」修改。同一組 PIN 同時用於活動管理、
表單管理與客戶資料紀錄。

**資料會不會不見**
紀錄存在平板瀏覽器本機。**清除瀏覽器資料會全部消失**，所以展後請盡快匯出。
